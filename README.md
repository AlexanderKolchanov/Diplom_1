## Дипломный проект. Задание 1: Юнит-тесты

## Автотесты для проверки программы заказа бургеров в Stellar Burgers

### 📋 Описание проекта

Проект содержит юнит-тесты для класса `Burger` из космической бургерной Stellar Burgers. Тесты покрывают все методы класса с использованием моков и параметризации.

### ✅ Выполненные требования

- **Покрытие тестами класса `Burger` - 100%** ✅
- **Использование моков** для изоляции тестов ✅  
- **Параметризация** тестов для проверки разных сценариев ✅
- **16 тестов** успешно проходят ✅


### 🧪 Реализованные тесты

**Класс TestBurger содержит 16 тестов:**

- `test_set_buns()` - установка булки
- `test_add_ingredient()` - добавление ингредиента  
- `test_remove_ingredient()` - удаление ингредиента
- `test_move_ingredient()` - перемещение ингредиента
- `test_get_price()` - расчет стоимости (с моками)
- `test_get_price_real_combinations()` - параметризованный тест стоимости
- `test_get_receipt_*` - тесты формирования рецепта
- Граничные случаи и дополнительные сценарии

### 🔧 Технологии и подходы

- **pytest** - фреймворк для тестирования
- **pytest-cov** - проверка покрытия кода
- **unittest.mock** - создание мок-объектов
- **Параметризация** - тестирование разных комбинаций данных
- **Фикстуры** - переиспользуемые тестовые данные

### 📊 Данные для тестов

В `constants.py` используются реальные данные из Stellar Burgers:

- **Булки**: Краторная булка N-200i (1255₽), Флюоресцентная булка R2-D3 (988₽)
- **Соусы**: Spicy-X, Space Sauce, Традиционный галактический, Антарианский
- **Начинки**: Мясо моллюсков Protostomia, Говяжий метеорит, Биокотлета и др.
